# Gopher, il web dimenticato

📺 [il video su YouTube](https://www.youtube.com/watch?v=L-W5bSCWDrw) · 📝 [l'articolo su www.thelinuxnerd.it](https://www.thelinuxnerd.it/gnu-linux-gopher-il-web-dimenticato/)

Gopher è un protocollo del 1991 che organizza i contenuti ad albero, come cartelle di un file system.
Veloce, senza cookie né popup. Esistono ancora server attivi (circa 325 censiti da Veronica nel 2022).

## esempio #1
Installare il client a riga di comando:

```
sudo apt-get install gopher
```

## esempio #2
Navigare nel gopher hole di The Linux Nerd, che raccoglie link ad altri progetti:

```
gopher gopher.thelinuxnerd.it
```

## esempio #3
Il Gopher Project, con la mega directory dei siti gopher divisi per categorie (hacking, home page, news):

```
gopher gopherproject.org
```

Frecce su e giù per muoversi tra i link, freccia destra per entrare e sinistra per tornare indietro.

## esempio #4
Un proxy web per vedere Gopher dal browser:

```
https://gopherproxy.meulie.net/
```
