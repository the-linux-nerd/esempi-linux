# curse of war

📺 [il video su YouTube](https://www.youtube.com/watch?v=qGi1XXOivBo) · 📝 [l'articolo su www.thelinuxnerd.it](https://www.thelinuxnerd.it/gnu-linux-curse-of-war/)

Un piccolo gioco di strategia in ASCII da giocare nel terminale, anche in multiplayer.
Si guida la crescita della propria popolazione per conquistare le miniere d'oro e battere gli avversari.

## esempio #1
Installazione, è nei repository ufficiali:

```
sudo apt-get install curseofwar
```

## esempio #2
Avvio della partita con le impostazioni predefinite (si parte come giocatore verde):

```
curseofwar
```

## esempio #3
Tasti principali, riassunti anche in basso nel gioco:

```
frecce   muovono il cursore e si mettono le bandiere dove deve andare la popolazione
s        rallenta il gioco (consigliato all'inizio)
f        accelera il gioco
p        pausa
v        crea un villaggio; di nuovo v lo migliora in città e poi in castello
```

I prezzi sono 150, 300 e 600 monete d'oro. L'oro arriva dalle miniere (simbolo del dollaro).
Le opzioni per personalizzare la partita e il multiplayer (modalità server) sono sulla pagina del gioco.
