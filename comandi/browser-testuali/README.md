# browser testuali
Browser per navigare sul web dalla linea di comando, utili su server senza interfaccia grafica.
Nel video li proviamo uno dopo l'altro e li confrontiamo. Il giudizio finale di Linux Nerd premia lynx.
In tutti, il tasto g apre un indirizzo e q esce.

## esempio #1
w3m: all'avvio propone un elenco di opzioni. Il cursore si muove come un puntatore del mouse.

```
w3m
```

## esempio #2
links: la schermata iniziale ha i comandi in basso. Il cursore salta da un elemento cliccabile all'altro.

```
links
```

## esempio #3
lynx: nessun colore, solo il grassetto per gli elementi interattivi. Molto leggibile.

```
lynx
```

## esempio #4
links2: simile a links, ma più veloce.

```
links2
```

## esempio #5
elinks: chiede subito l'indirizzo da visitare. Lo sfondo chiaro lo rende poco leggibile.

```
elinks
```
